# 开工清单

在动手前一次把资料要齐。资料来得越晚，返工越大：结构照片晚到，模型要重建；参数晚到，已经做好的数字镜头要重做；配音晚到，整片节奏要重对。

## 怎么用

1. 把下面的清单发给用户，请对方一次给齐。
2. 收到后逐项标记：**已有** / **缺** / **不需要**。
3. 对每个「缺」的项，说清楚会影响哪些镜头，以及先怎么顶上（占位图、定性刻度、按字数估时长……），等资料到了再换。
4. 缺失项影响建模或核心卖点的，先停下来等资料，不要按假设做。

## 清单

| 类别 | 要什么 | 用在哪 | 缺了怎么办 |
|---|---|---|---|
| **实物结构** | 多角度照片：正面、背面、侧面、拆开后的内部；关键部件特写；外形尺寸（有 CAD 或三视图最好） | 建模，以及建模确认关 | 不能按想象建模。先停下来要资料，或者只做外观、不做内部 |
| **参数资料** | 规格书、铭牌、检测报告、认证证书里准备上屏的参数 | 数字镜头、科普图形 | 用定性表达，不出数字；画面上不编数据 |
| **口播** | 定稿或草稿的口播文本，标明哪些句子不能改 | 分镜、时长 | 先出分镜框架，口播位置留空 |
| **配音** | 配音音频，最好每句一个文件；没有的话，临时用 AI 合成的也行 | 锁节奏（见 `audio-sync.md`） | 先按字数估时长，配音到了再对一遍 |
| **交付规格** | 画幅（横屏、竖屏）、分辨率、帧率、时长上限、文件格式、要不要无字幕版或分层素材 | 合成设置、渲染命令 | 默认 1920×1080、30fps、H.264 MP4，并告诉用户这是默认值 |
| **品牌素材** | logo 原文件（最好是透明底或矢量格式）、品牌色、指定字体、禁用的说法 | 定版、字幕、配色 | 定版先留空，剪辑时再加；字体用系统默认 |
| **使用场景** | 产品在哪里用：客厅、厨房、车里、户外、身上……有没有实拍的场景素材 | 场景镜头、与实拍衔接 | 做简洁的 CG 场景，或者只在黑底上展示产品 |
| **审片方式** | 谁来审、怎么反馈（按秒数、按镜头号）、要审几轮 | 安排小样和正式成片 | 默认先出小样审节奏，再出正式成片 |

## 常见的资料矛盾

收到资料后先交叉核对，发现矛盾就先指出来，不要替用户圆：

- 「数量 × 单件参数」和总参数对不上，比如单颗功率乘以颗数，远超电源的额定输出；
- 照片里的数量、排布，和文字描述对不上；
- 宣传口径和检测报告的数值不一样。

遇到这类矛盾，先列出你的推断（比如「多路共用电源，同一时间只有一部分满功率工作」），请用户找品牌方确认。确认前，画面上只出能确认的部分。
