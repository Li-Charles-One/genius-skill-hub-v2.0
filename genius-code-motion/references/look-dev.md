# 建模、材质与布光

## 建模确认（出分镜前必须过）

1. **从资料读结构**：照片、拆机图、规格书是依据。逐项读出部件、数量、排布、分组、标记、尺寸。数量能数就放大照片数，数不清就写「约」，并说明是怎么数的。
2. **列结构清单给用户看**，例如：「4 条灯条顺长边排，每条分 2 段，每段约 24 颗，3 颗一组焊在小板上；Y、W 两种灯珠交替；驱动在中间」。
3. **渲一张模型静帧**，和清单一起交给用户确认。
4. 用户指出的偏差（比如「驱动其实歪了，做的时候摆正」）直接按用户说的改，不要照搬照片里的偶然状态。

## 建模手法

- **单位用米**，按真实尺寸建；关键的小部件可以适度放大，保证看得清（比如把 2835 灯珠放大 1.5–2 倍）。
- **圆角板件**：用圆角矩形 `Shape` 加 `ExtrudeGeometry`（带倒角）；小方块用 `RoundedBoxGeometry`。
- **朝下的面**：形状在 XY 平面，`rotation.x = +π/2` 以后正面朝下，形状的 y 对应世界的 z。
- **导线**：`CatmullRomCurve3` 加 `TubeGeometry`，沿着边缘和底盘布线。悬在空中横跨间隙的导线看着像棍子。
- **重复部件**（几百颗灯珠）：几何体共用一份，材质按需每个一份，方便单独控制亮度；数量在几百这个级别，直接用多个 mesh 就够，不必上 InstancedMesh。
- **分层装配**：会一起移动的部件（灯条、驱动、导线）放进同一个 group，拆解时整体偏移，连接关系不会断。

## 程序化贴图（Canvas 2D）

- 用 Canvas 画出走线、焊盘、丝印、铭牌、地板、装饰画，转成 `CanvasTexture`，设 `colorSpace = SRGBColorSpace`，`anisotropy` 调高。
- `ShapeGeometry` 的 UV 等于形状坐标（米）：贴整张图时设 `repeat = 1/尺寸`、`offset = 0.5`。
- **铭牌、规格这类文字直接按真实参数画**，近景能读出来，本身就是科普信息。
- **微距镜头**：整块贴图的分辨率不够，在主角部件周围叠一张高分辨率补丁，边缘用渐变 alpha 羽化，再加 `polygonOffset` 防止闪烁。补丁和底图用同一个绘制函数，内容才对得上。
- 噪点、颗粒这类随机元素用固定种子的伪随机函数生成。

## 布光配方

| 镜头 | 灯光 |
|---|---|
| 拆解、结构展示 | 一盏方向光从斜下方打主光，加半球光补暗部 |
| 微距 | 一盏聚光贴着目标打低角度侧光，强度 = 目标照度 × 距离²；发光体自己再加一盏很弱的点光，照亮周围 |
| 整板点亮 | 板子中心前方加一盏弱点光，模拟所有发光体的溢光，强度跟点亮数量走 |
| 室内 | 灯具位置一盏点光（开阴影），加半球光和一盏低处补光模拟地面反射；房间变大时补光按面积比例减弱 |

- 所有灯光强度都按帧号插值，镜头之间交接时淡入淡出。
- 场景里同时有「产品棚拍」和「室内」时，给所有室内材质的颜色统一乘一个「房间亮度」系数。开灯前系数为 0，房间全黑，棚拍光就照不亮房间。
- 镜头运动会改变灯光入射角，照度可能跳变。抽帧发现亮度跳时，在这一段单独把主光压一下。

## 发光与辉光

- 发光体用 `emissive`，强度大于 1，并设 `toneMapped: false`，后期辉光才会被触发。
- 微距时发光体占满画面，强度给低一些；拉远后发光体变小，需要更高的强度才撑得起辉光。强度按镜头远近插值。
- 透明材质（透镜、玻璃）的自发光会被不透明度缩放，调大就变成白色实心。这类材质的自发光要很低，光集中在内部的发光芯上。
- 双色温、多色产品：交替排布的两种发光体分别用两种发光颜色，熄灭时的底色也要区分。熄灭态的颜色不能太深，否则看着脏。

## 拆解爆炸图

- 沿一个轴拉开，层间距要足够大（几十厘米级），镜头仰角压低（约 25°），各层才不会在画面上互相遮挡。
- 不要用半透明表现「看进去」：黑底上的半透明物体像一块深灰色的板。
- 标注根据锚点在画面左半边还是右半边，自动决定引线往左还是往右；每个标注至少停留 2 秒。
- 拆开和装回都要给时间，装回的同时可以开始下一个镜头的运镜。

## 室内场景

- 前墙去掉，镜头从外面看进去；地面、顶面、侧墙往镜头方向延伸到画面外，画面边缘就不会露出黑边。
- 要演示面积变化时，墙、地板、家具都相对房间边界定位；地板贴图的 repeat 跟着尺寸变，木纹才不会被拉伸。
- 加法混合的地面光效要用 `clippingPlanes` 限制在地板范围内。

## 质感升级阶梯（只用 Three.js）

按投入产出比从高到低。这一节的手法在本流程里**还没有实际做过**，第一次用时先拿一个镜头试效果和渲染时间：

1. **环境光**：用 Three.js 自带的 `RoomEnvironment` 经 PMREM 生成环境贴图，不用下载文件，白色塑料和金属马上有反射。
2. **环境光遮蔽**：用 N8AO 接进后期管线，物体接触处会有自然的暗角。
3. **真折射**：透镜、玻璃用透射材质，按材料设折射率（PMMA 约 1.49）。
4. **材质细节**：程序化生成法线和粗糙度贴图；要照片级贴图就从免费素材站下载，下载前先问用户。
5. **运动模糊**：Remotion 的相机运动模糊组件。
6. **超采样和调色**：按 4K 渲染再缩到 1080p，加 LUT 统一色调。
7. **路径追踪**：`three-gpu-pathtracer` 是 Three.js 的路径追踪库，每帧要累积很多次采样，比实时渲染慢几个数量级。只用在最吃质感的一两个镜头上。
