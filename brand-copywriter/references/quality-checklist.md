# 质量自检清单

## 执行前

- [ ] 已读取 copy_frameworks.md
- [ ] 已读取 writing_styles.md
- [ ] 已读取 anti-slop-pass.md
- [ ] 两个框架 AND 写作规则 AND 净化流水线都在上下文中

## 输入检查

- [ ] 文案类型/平台已确认（中文平台已区分：小红书 vs 公众号 vs 抖音……不是笼统的"社交媒体"）
- [ ] 目标受众清晰（中文语境已区分圈层）
- [ ] 核心转化点明确

## 英文输出检查

- [ ] 两个版本用了不同框架
- [ ] 没有禁用词（参考 writing_styles.md 英文禁用词列表）
- [ ] 没有懒惰形容词
- [ ] 用具体数字代替模糊表述
- [ ] CTA 具体且命名了动作
- [ ] 写给一个人，不是一群人

## 中文输出检查

- [ ] 没有 AI 味句式（"家人们谁懂啊""不得不说""绝绝子""YYDS""狠狠地""就是说"）
- [ ] 没有八股模板（"首先其次再次最后综上所述"）
- [ ] 没有平台违禁词（极限词/功效承诺/诱导词/引流词/夸张收益）
- [ ] 口语化但不口水化——不堆砌网络梗，不用过气流行语
- [ ] 用短句和逗号做节奏，不是西式长复合句
- [ ] 数字用阿拉伯数字
- [ ] CTA 有力但不夸张（中文特有的"免费领"、"马上试"、"去看看"）
- [ ] 配合平台格式约束（参考 platform-rules.md 各平台硬限制）
