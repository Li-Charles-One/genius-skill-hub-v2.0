# 平台适配规则

## 全球平台

| 平台 | 硬约束 |
|------|--------|
| **Facebook/Instagram 广告** | 125 字符前折叠（hook 前置），主文案最多 1000 字符 |
| **TikTok/Reels** | 前 3 秒 = hook，15-60 秒脚本，口语化 |
| **LinkedIn** | 专业但人性化，首行 = hook，最多 1300 字符 |
| **YouTube** | 前 5 秒关键，长视频用时间戳 |
| **Landing Page** | 首屏 = 标题 + 副标题 + CTA，可扫读段落 |
| **Email** | 主题行 <50 字符，预览文字很重要，一封邮件一个 CTA |
| **Sales Page** | 允许长文案，多处证明点，建议 FAQ |

## 中文平台

| 平台 | 硬约束 |
|------|--------|
| **微信公众号** | 标题 ≤64 字（建议 13-15 字手机端单行），正文 2000-3000 字最佳阅读，字号 15px、行距 1.75 倍，全文颜色 ≤3 种，段落之间空行、每段不超过一屏 |
| **小红书** | 标题 ≤20 字（建议 10 字），正文 ≤1000 字（建议 600-800 字），竖版 3:4 图片 6-9 张最佳，**严禁极限词和功效承诺**（一条违规即限流），禁止直接引微信/外链，私信导流首次违规禁言 48h |
| **抖音** | 描述 ≤55 字（超过折叠），**前 3 秒必须钩子**，口播简洁直接，禁止"最/第一/神器"等极限词，禁止功效词（祛斑/美白/防紫外线），禁止夸张收益话术（月入X万/躺赚），新规 60+ 违禁词覆盖诱导互动/引流私域/刷数据 |
| **微博** | 原创 ≤5000 字，信息流仅显示前 **140 字**（余下"展开全文"），评论 ≤140 字，建议插入 1-2 个 #话题#，蹭热搜需内容相关否则降权，"头条文章"全站权重最高（5 倍展示） |
| **知乎** | 回答优质标准 ≥500 字，排版清晰言之有物，**严禁 AI 创作或 AI 辅助**（致知计划明确禁止），开头 40 字吸睛句，专业严谨有数据支撑，鼓励第一人称真实经验分享，不友善/辱骂 → 删除折叠 |
| **B站** | 标题用中文，封面文字 ≤8 字，简介含 3-5 个关键词做 SEO，标签 5-8 个，0-15 秒明确钩子，爆点均匀分布（不超过 2 分钟冷区），设计至少 3 个弹幕/评论引爆点，黄金发布时间 20:00-21:00 |

## 中文特有文案类型

| 类型 | 定义 | 主要平台 | 写作要点 |
|------|------|---------|---------|
| **种草文案** | 以真实体验分享激发购买欲，非硬推卖点，口语化带情绪 | 小红书、抖音、微博 | 讲真实感受、朋友口吻、一对一分享感、具体场景 |
| **私域话术** | 微信个人号/社群/朋友圈的一对一或群发话术 | 微信（私域）、企业微信 | 亲和力>推销感、信任在前、分段短句、适度人格化 |
| **裂变海报** | 以"转发+截图"为机制的推广海报文案 | 微信朋友圈、社群 | 利益点前置、紧迫感但不用极限词、一个 CTA |
| **直播话术** | 直播口播脚本：开场留人→塑品→逼单→转款→憋单 | 抖音、快手 | 口语化、节奏快、重复卖点、倒数库存/时间 |
| **素人笔记** | 普通人视角的小红书笔记，非 KOL 的"真实分享" | 小红书 | 语气像发朋友圈、"我之前也不懂"开头、用手机拍的真实图片 |
| **品效合一文案** | 品牌调性 + 转化率兼顾的信息流广告 | 抖音信息流、微博 | 前 3 秒品牌感 + 中段产品力 + 结尾强 CTA |
| **拔草/避雷文案** | 曝光产品问题帮用户"排雷" | 小红书 | 真实体验、具体问题、不做全盘否定 |
