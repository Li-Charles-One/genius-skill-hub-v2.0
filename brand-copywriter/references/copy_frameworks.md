## 14 种框架详解

### 1. AIDA — Attention → Interest → Desire → Action
万能框架。适用于几乎所有文案类型。
- **A**：Hook 停住滚动（大胆声明、问题、惊人数据）
- **I**：解释为什么重要，连接到他们的世界
- **D**：建立情感渴望，展示转型、卖点、社会认同
- **A**：清晰 CTA，告诉下一步做什么

### 2. PAS — Problem → Agitate → Solution
痛点驱动。快速、情感化、直接。
- **P**：清晰陈述痛点，让他们感觉被看见
- **A**：拧紧刀子；展示后果；未来化痛点
- **S**：展示产品作为解脱方案

### 3. BAB — Before → After → Bridge
转型框架。展示从痛苦到可能的旅程。
- **B**：描绘当前痛苦现实，具体且有共鸣
- **A**：展示渴望的转型状态，生动且有情感
- **B**：你的产品是从 Before 到 After 的桥梁

### 4. FAB — Features → Advantages → Benefits
产品聚焦框架。把规格翻译成欲望。
- **F**：产品有什么/能做什么
- **A**：为什么这个功能比替代品好
- **B**：客户实际得到什么

### 5. PASTOR — Problem → Amplify → Story → Transformation → Offer → Response
长文案框架。适合 Sales Page 和 Webinar。
- 完整的说服弧线，从问题到行动

### 6. ACCA — Awareness → Comprehension → Conviction → Action
B2B/SaaS 常用。适合需要理性说服的场景。

### 7. QUEST — Qualify → Understand → Educate → Stimulate → Transition
再营销和 Email 序列。先筛选再转化。

### 8. SLAP — Stop → Look → Act → Purchase
TikTok/短视频。快速节奏，3秒hook。

### 9. G.R.A.B — Goal → Result → Action → Benefit
短视频/TikTok。开门见山。

### 10. 5-Point — 五个卖点
产品发布和 Sales Page。结构化展示多个价值点。

### 11. STAR Story — Situation → Task → Action → Result
UGC/网红脚本。故事驱动。

### 12. 4P — Promise → Picture → Proof → Push
转型类。教练、课程。

### 13. PPPP — Picture → Promise → Prove → Push
传统广告框架。

### 14. 4U — Urgent → Unique → Useful → Ultra-specific
标题和 Hook 优化。
