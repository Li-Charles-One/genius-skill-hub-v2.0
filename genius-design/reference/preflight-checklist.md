# Pre-Ship Checklist

After generating a DESIGN.md, run this 12-item gate before delivering. Not optional.

## The 12 Checks

### Color
- [ ] **One accent, one palette**: No second accent leaking from a different hue family. One neutral family (zinc/slate/stone) used consistently.
- [ ] **No cream default**: Background is NOT in the warm-neutral band (OKLCH L 0.84-0.97, C < 0.06, hue 40-100) unless explicitly requested.
- [ ] **Contrast floor**: Body text ≥ 4.5:1 against background. Button text ≥ 4.5:1 against button bg. No white-on-white CTAs.

### Typography
- [ ] **Font is not Inter** (unless explicitly chosen). Nor Fraunces, nor Instrument_Serif.
- [ ] **Serif justified**: If a serif is present, there's a one-sentence brand justification. Not "it felt premium."

### Layout
- [ ] **Hero fits viewport**: Headline ≤ 2 lines, subtext ≤ 20 words, CTA visible without scroll.
- [ ] **No three-equal-cards**: The generic "icon + heading + text × 3" feature row is absent.
- [ ] **Eyebrow discipline**: Count of uppercase-tracked micro-labels ≤ ceil(sections / 3).

### Content
- [ ] **No em-dashes**: Zero `—` or `–` anywhere in visible text.
- [ ] **No AI buzzwords**: "Elevate," "seamless," "unleash," "next-gen," "game-changer" — absent.

### Design System
- [ ] **One system**: If Fluent/Material/Carbon/Primer was chosen, it's the ONLY system. No mixing.
- [ ] **Dark mode**: Tokens defined for both light and dark. Page has one consistent theme.

---

If any box cannot be ticked, fix before delivering the DESIGN.md.
