# 花字配方

参考实现：工作台 `src/shared/TechTitle.tsx`（示例合成 `TechTitleDemo`）；工作台 `src/ceiling-light/index.tsx`（吸顶灯测评）里的 `SongZhuangTitle`（两行）、`JiCaiTitle`（单行）是用 props 配出来的实例。它支持 `lines`（每行文字、坐标、入场帧、光带长度）、`size`（字号）、`ring`（HUD 圆环圆心）三个 props，单行、多行都用它。照同类参考图做新花字时，先考虑传 props，不够用再改组件或另写。

## 先拆参考图

把参考图拆成从下到上的层，每层回答三个问题：形状、颜色、怎么动。科技光效花字通常是：

| 层 | 典型样子 |
|---|---|
| 装饰 | HUD 圆环、虚线圈、小圆点、细线 |
| 光带 | 字下半部的横向辉光，左亮右淡 |
| 引导符 | 行首 `>>>` 箭头 |
| 字底层 | 深色投影 + 彩色外发光 |
| 字面层 | 白到灰的竖向渐变，斜体粗字 |
| 高光 | 一道斜向扫光 |

参考图里有本机没有的字体（标题黑、庞门正道之类）时，先用思源黑体 Heavy + `skewX(-12deg)` 近似，并告诉用户可以换免费商用的标题字体；下载字体要先征得同意。

## 各层配方

- **斜体粗字**：`fontWeight: 900`，`transform: skewX(-12deg)`，`letterSpacing: 4`，`whiteSpace: 'nowrap'`。
- **字面渐变 + 扫光**：`color: transparent` + `backgroundClip: 'text'`，背景叠两层：上层是随帧移动的斜向白色亮带（`linear-gradient(105deg, 透明 shine-12%, 白 shine%, 透明 shine+12%)`），下层是 `#fff → #fff 45% → 浅灰 75% → 中灰 100%` 的竖向渐变。`shine` 在入场后约 1 秒内从 -40 走到 140。
- **字底层**：同样的字再放一层在下面，深色填充，`textShadow` 写深色投影（向下 6px、模糊 10px）和彩色外发光（模糊约 28px）。不要和渐变层合成一层。
- **光带**：三层叠在每行字下半部（中心约在字号 × 0.78 处）：
  1. 宽辉光：高约 76、`blur(18px)`，横向渐变两端透明、左段最浓；
  2. 亮芯：高约 24、`blur(6px)`，颜色更亮；
  3. 细亮线：高 3px，加同色 `boxShadow` 发光，略向右错开。
  宽度从 0 拉到满就是「从左往右拉出」。整组外层用一个 `opacity` 统一控制浓淡。
- **引导符**：SVG 画三个折线 `>`，透明度从左到右递增，`drop-shadow` 发光。
- **HUD 圆环**：SVG 里一个实线圈、一段高亮弧（`strokeDasharray`）、一个虚线小圈、一段外圈弧、两三个小圆点；整体随帧慢转，内外圈反向转。整体透明度压低，别抢字。

## 入场节奏（30fps）

| 帧 | 动作 |
|---|---|
| 0–30 | 圆环从 0.7 倍放大到 1 倍并淡入 |
| 2–24 | 光带逐行拉出（每行比字早约 4 帧） |
| 4–20 | 箭头从左滑入 |
| 6–22，下一行 +8 | 字从左 160px 处飞入，模糊 10px → 0，淡入 |
| 30–62 | 字面扫光一次 |
| 之后 | 定版；不做出场，剪辑里淡出 |

总长 5 秒（150 帧）够剪辑师取用；用户要配合口播卡点时，按口播时间点挪 `start`。

## 排版

- **两行错位**：第二行向右错开约 2 个字宽，行距约字号 × 1.3。
- **单行**：整行在画面水平居中，垂直位置 = (1080 − 字号 × 1.2) / 2。字数多时降字号，确保左边箭头不出画（10 个字约用 128）。圆环圆心放在整行中心。
- 光带长度按字数估：字数 × (字号 + 字间距) + 约 200。

## 配色

- 光效的主色由用户定（蓝、红等）。换色时光带、亮芯、细线、箭头、圆环、外发光要一起换，字面渐变的灰也要往同一色温靠，或保持中性灰。
- 用户说「颜色淡一点 / 透明度低一点」：先降光带组的整体 `opacity`（如 0.55），再降圆环和箭头；字边外发光单独压到 0.2 左右。
- 用户说「字的颜色少一点」：字面渐变改回中性灰，字底层投影改中性黑，外发光压低。
- 叠在亮画面上会用到时，保留深色投影，否则白字看不清。
